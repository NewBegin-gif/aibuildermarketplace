Before you buy

Bring these questions to your next software evaluation.

What does one finished piece of work cost?

Check the allowance, how much each action uses, whether retries count and what happens when you run out. Compare the work you need to finish, not the credit balances. Read more →

What will this connection be allowed to do?

Look for the supported assistant, the plan it needs and the permissions it gets. Reading information and changing it are different risks. Check the vendor's documentation before connecting an account. Read more →

What evidence supports a visibility claim?

Ask what was measured and whether other changes could explain the result. Publishing a file by itself does not show that it caused more visits or citations. Read more →
