What actually drives the quote

The published ladder is gone. Airia used to show a free tier, Individual at around $50 a month and Team at around $250, with Enterprise on quote. As of 20 August 2026 that page no longer exists: both airia.com/pricing and www.airia.com/pricing redirect to a demo-request form, and there is no amount anywhere on the site. If you find $50 or $250 quoted for Airia — including in an older version of this review — treat it as historical.

That change matters more than it looks, because the self-serve tiers were the only way to try the platform without a sales conversation. With them withdrawn, there is no priced entry point at all, and the honest consequence is that a small team can no longer evaluate this product on its own terms. Whether that is a problem depends on whether you were the customer anyway — and mostly you were not.

Airia's value is governing AI across a whole organisation: discovering what is already running, including the tools nobody approved, enforcing policy at the execution layer before an action fires, and producing compliance evidence, with the agent builder now one pillar among four. That only repays its cost at organisational scale. A team that wants one chatbot was always buying far more platform than it needed; the withdrawn tiers simply make that explicit.

So the questions for the demo are the enterprise ones. Ask what the licence is counted on — agents, workflows, seats, executions or model calls — because those scale at wildly different rates and the answer determines your bill more than the headline does. Ask which capabilities sit behind the Enterprise line specifically; SSO/SAML, audit logs and dedicated support were the published differentiators, and governance features that arrive only at the top tier are exactly the ones a compliance-driven purchase depends on.

And ask what happens as agent count grows, because a platform bought to standardise AI across an organisation is a platform whose usage is designed to increase. One practical note while you wait for a quote: the constraint most likely to bite is not price but ingestion. Uploaded audio and video are not retrievable the moment you add them, because text extraction runs after speech-to-text rather than in real time.

And the File Upload connector rejects some file types outright, including files containing script content such as PHP or JS. Test the platform against your actual documents during any pilot.

How to actually use Airia

First value in Airia comes from shipping one working agent, and the path is guided. You accept an email invitation, set a password, then create a Project to hold your components. Inside it you add a model from the model list, then a Data Source; the docs steer you to the File Upload connector as the starting point. Then drag the pieces onto a canvas, wiring Input to Data Source to Model to Output, save, and test.

To actually use the agent, you attach an interface so it shows up in Airia Chat under Apps. Uploaded audio and video are not retrievable the moment you add them, because text extraction runs after speech-to-text processing rather than in real-time. The File Upload connector also rejects some file types outright, such as files containing script content like PHP or JS, and certain image formats fail through the Microsoft connectors.
