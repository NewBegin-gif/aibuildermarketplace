FAQ

Quanto custa o AISDR por mês no Brasil?

O AISDR custa entre R$ 0 (plano gratuito) e R$ 2.497/mês (Enterprise). O plano Starter sai por R$ 297/mês, enquanto o Professional custa R$ 897/mês. Pagamentos anuais oferecem 20% de desconto em todos os planos pagos.

Qual a diferença entre os planos do AISDR?

O plano Free permite 100 contatos/mês, Starter oferece 1.000 contatos com automação básica, Professional inclui 5.000 contatos com IA avançada e integrações, enquanto Enterprise oferece contatos ilimitados, suporte dedicado e recursos customizados.

O AISDR tem custos ocultos ou taxas extras?

Sim, existem custos adicionais como taxa de setup (R$ 497 para Professional/Enterprise), excesso de contatos (R$ 0,15 por contato extra), integrações premium (R$ 97/mês cada) e suporte prioritário (R$ 197/mês para planos básicos).

Quando vale a pena upgrade do Free para o plano pago?

O upgrade vale a pena quando você precisa processar mais de 100 contatos/mês, usar automação de follow-up, integrar com CRM ou acessar analytics avançados. Geralmente empresas fazem upgrade após 2-3 meses de teste.

Como negociar desconto no plano Enterprise do AISDR?

Para negociar desconto no Enterprise, comprove volume alto (10.000+ contatos/mês), negocie contratos anuais ou bi-anuais, solicite proposta customizada e compare com concorrentes. Descontos típicos variam entre 15-30% para contratos longos.

Estratégias de Otimização de Custos

1. Comece com Plano Starter + Add-ons Específicos

Em vez de pular direto para Professional, teste Starter (R$ 297) + AI Writing (R$ 97) = R$ 394/mês. Economia de R$ 503/mês inicialmente.

2. Negocie Contratos Anuais

  • 20% desconto automático no pagamento anual
  • Professional anual: R$ 7.176 vs R$ 10.764 mensal
  • Economia: R$ 3.588/ano

3. Monitore Usage para Evitar Overages

Configure alertas quando atingir:

  • 80% do limite de contatos
  • 90% do limite de usuários
  • Analise métricas semanalmente

4. Use Integrações Nativas (Não Add-ons)

AISDR Professional inclui 25+ integrações nativas. Evite add-ons caros:

  • Use Zapier integration (incluída) em vez de integrações premium
  • Configure webhooks básicos via API incluída

5. Otimize por Usuário

Em vez de adicionar usuários extras (R$ 47/cada), use:

  • Compartilhamento de contas para tasks específicas
  • Rotação de usuários por projeto
  • View-only access para stakeholders

Dicas de Negociação Enterprise

1. Timing da Negociação

  • Melhor período: Dezembro (fim do ano fiscal)
  • Trimestres: Últimas 2 semanas de cada trimestre
  • Evite: Janeiro-Fevereiro (quotas resetadas)

2. Argumentos para Desconto

  • Volume: Comprove 10.000+ contatos/mês
  • Contrato longo: 2-3 anos garantidos
  • Case study: Ofereça ser referência
  • Pagamento antecipado: 12 meses à vista
  • Múltiplas ferramentas: Bundle com outros produtos

3. Termos de Contrato a Negociar

  • Price lock: Preço fixo por 36 meses
  • Scaling discount: Desconto maior conforme crescimento
  • Exit clause: Cancelamento com 60 dias
  • SLA personalizado: 99,95% uptime
  • Dedicated IP: Incluído sem custo extra

4. Descontos Típicos Conseguidos

  • Contrato anual: 20-25% desconto
  • Contrato bi-anual: 30-35% desconto
  • Enterprise 500+ users: 40-50% desconto
  • Nonprofits/Educação: 50% desconto

Limitações do Plano Free - Quando Fazer Upgrade

O Que Funciona no Free

  • Testar a interface e usabilidade
  • Prospecção básica para validar conceitos
  • Pequenos testes A/B manuais
  • Onboarding da equipe

O Que NÃO Funciona

  • Volume: 100 contatos/mês é muito limitado
  • Automação: Zero follow-up automatizado
  • Integrações: Só Gmail/Outlook básico
  • Relatórios: Métricas muito superficiais
  • Suporte: 72h+ de resposta
  • Marca: "Powered by AISDR" em todos emails

Sinais para Fazer Upgrade

  1. Atingir limite de contatos 2-3 vezes no mês
  2. Precisar de follow-up automático (maior ROI)
  3. Equipe com 2+ pessoas prospectando
  4. Integração com CRM se tornar necessária
  5. Métricas detalhadas para otimização
