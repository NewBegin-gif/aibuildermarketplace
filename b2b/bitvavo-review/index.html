When the paid plan is worth it

Bitvavo sells no subscription and has no paid plan to compare against a free one. The only low/high split is the volume-based maker/taker fee schedule, which the API documentation calls a "price tier" and files under the default "Category A", and which the account-fees endpoint returns next to "Your trading volume in the last 30 days measured in EUR". The docs state that the first tier in the Bitvavo fee structure is 0. The schedule itself lives on the public fees page, which refused our automated requests, so we quote no thresholds or percentages here rather than repeat figures from a page we could not open. Worth knowing about what a better tier does not fix: the documented default rate limit of 1000 weight points per minute is nowhere presented as tier-linked. A better tier also does nothing about the mandatory operatorId field, which the FAQ says has to be included in all create, update and cancel order requests, nor about the per-market minimum order sizes that the same FAQ blames for rejected orders.

How to actually use Bitvavo

The vendor route is short. Create a private account at account.bitvavo.com/create, or contact the professional team at professional@bitvavo.com for a corporate account. The docs list enabling two-factor authentication under Before you start: scan a QR code with an authenticator app, then enter the 6-digit 2FA code it shows. Then, under Settings, open the API tab, add a new key, name it, set an IP whitelist, and choose among the six permissions: View access, Trade, Withdraw, Include all subaccounts, Internal Transfer and Administrative; you finish by entering a 2FA code and selecting Confirm. The secret is shown once and cannot be retrieved later. Distilled from Vendor material only — Bitvavo's own developer documentation (the get-started, rate-limits and FAQ pages plus the account-fees and market-fees endpoint pages), with the credential requirement cross-checked against the official Bitvavo Python SDK README on GitHub; we found no independent walkthrough worth citing.
