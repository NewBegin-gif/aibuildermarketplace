FAQ

Чи можна перейти з меншого плану на більший без додаткових витрат?

Так, Hostinger дозволяє безкоштовний апгрейд планів у будь-який час. Ви доплачуєте лише різницю в ціні пропорційно до залишкового терміну підписки. Даунгрейд можливий лише при поновленні контракту.

Скільки коштує міграція сайту на Hostinger?

Міграція WordPress сайтів безкоштовна для всіх планів. Команда підтримки перенесе до 1 сайту безкоштовно протягом 24-48 годин. Для складних сайтів або термінових міграцій може знадобитися додаткова плата $50-100.

Чи справді безлімітний трафік у Hostinger?

Технічно трафік безлімітний, але існують "fair use" обмеження. На Single плані реально доступно ~100GB/місяць, на Premium ~300GB/місяць. При перевищенні Hostinger може запросити апгрейд плану, але не заблокує сайт.

Які реальні швидкості завантаження можна очікувати?

На Premium плані середня швидкість завантаження WordPress сайту становить 500-800ms (за даними GTMetrix). Business план показує 300-600ms завдяки 4x продуктивності. Cloud плани демонструють 200-400ms з оптимізованою конфігурацією.

Коли варто переходити з shared на cloud хостинг?

Перехід доцільний при досягненні 50,000+ відвідувачів/місяць, частих пікових навантаженнях, або коли сайт регулярно сповільнюється. Для e-commerce з оборотом $5000+/місяць cloud план стає критично важливим для стабільної роботи.
