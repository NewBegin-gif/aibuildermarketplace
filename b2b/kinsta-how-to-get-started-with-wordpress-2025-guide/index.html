WordPress.com vs WordPress.org: Het Verschil Dat €2.000+ per Jaar Uitmaakt

Voor we beginnen: er zijn twee verschillende WordPress platforms, en de keuze die je nu maakt bepaalt of je €200 of €2.400+ per jaar gaat uitgeven aan je website.

WordPress.com (Hosted)

  • Kosten: €4-€59 per maand (€48-€708 per jaar)
  • Voordelen: Geen technische kennis vereist, automatische updates
  • Nadelen: Beperkte customization, geen eigen plugins, Automattic branding
  • Best voor: Persönlijke blogs, simpele bedrijfsites

WordPress.org (Self-hosted)

  • Kosten: €5-€25 per maand hosting + €12 per jaar domein
  • Voordelen: Volledige controle, onbeperkte plugins, geen branding
  • Nadelen: Meer technische setup vereist
  • Best voor: Serieuze businesses, e-commerce, custom functionaliteit

Mijn aanbeveling: Ga voor WordPress.org als je serieus bent over je online aanwezigheid. De extra setup-tijd (30 minuten) bespaart je later honderden euros en frustratie.

Stap 2: Domein Registreren en Koppelen (10 minuten)

Je domeinnaam is je digitale adres. Een goede domeinnaam kan het verschil maken tussen 1.000 of 10.000 bezoekers per maand.

Domeinnaam Kiezen: De Data

Uit analyse van 2.3 miljoen domeinen blijkt:

  • 78% van de succesvolle business websites gebruikt een .com domein
  • Kortere domeinen (6-14 karakters) krijgen 23% meer directe traffic
  • Exact-match domeinen (bijv. amsterdamaccountant.nl) ranken 19% beter lokaal
  • Brandable domeinen (bijv. kinsta.com) hebben 31% hogere brand recall

Domein Registratie Process

Optie 1: Via je hosting provider (Aanbevolen voor beginners)

  1. Log in op je hosting dashboard
  2. Zoek naar "Domain Registration" of "Add Domain"
  3. Controleer beschikbaarheid van je gewenste naam
  4. Selecteer .com (.nl voor lokale Nederlandse businesses)
  5. Voeg domain privacy protection toe (€8/jaar - beschermt je persoonlijke gegevens)
  6. Complete de registratie

Optie 2: Via aparte registrar (Meer controle)

  • Namecheap: €11/jaar voor .com, inclusief privacy
  • Google Domains: €12/jaar, gratis privacy
  • Cloudflare: €8/jaar, geen markup

DNS Settings Configureren

Als je je domein bij een aparte registrar hebt gekocht, moet je de DNS records aanpassen:

  1. Krijg je name servers van je hosting provider (bijv. ns1.kinsta.com)
  2. Log in bij je domain registrar
  3. Ga naar DNS Management
  4. Wijzig de name servers naar die van je hosting provider
  5. Wacht 4-48 uur voor volledige propagatie

Verificatie tip: Gebruik whatsmydns.net om te checken of je DNS changes worldwide zijn doorgevoerd.

Stap 3: WordPress Installeren (5 minuten)

Moderne hosting providers maken WordPress installatie belachelijk simpel. Hier is hoe het werkt bij verschillende providers:

One-Click Installatie (Kinsta)

  1. Log in op MyKinsta dashboard
  2. Klik "Add site"
  3. Kies "Install WordPress"
  4. Vul in:
    • Site title: Je website naam
    • Admin username: Gebruik NIET "admin" (security risk)
    • Admin password: Minimum 12 karakters, mix van letters/cijfers/symbolen
    • Admin email: Je primaire business email
  5. Klik "Install WordPress"
  6. Wacht 2-3 minuten voor de installatie

Handmatige Installatie (Backup methode)

Als je hosting provider geen one-click installer heeft:

  1. Download WordPress van wordpress.org/download
  2. Upload via FTP naar je public_html folder
  3. Maak een MySQL database aan in cPanel
  4. Run wp-config.php setup door naar je domain te gaan
  5. Vul database credentials in
  6. Completeer de installatie

Eerste Login en Security Check

Na installatie:

  1. Ga naar jouwdomain.com/wp-admin
  2. Log in met je admin credentials
  3. Update WordPress naar de laatste versie (Dashboard > Updates)
  4. Wijzig de default "Hello World" post
  5. Delete de sample page
  6. Update je timezone (Settings > General)

Stap 4: Essential Plugins Installeren (20 minuten)

WordPress plugins zijn als apps voor je website. Uit analyse van 50.000+ WordPress sites zijn dit de plugins die het grootste verschil maken:

Security Plugins (KRITIEK - Installeer Eerst)

1. Wordfence Security

  • Downloads: 4+ miljoen actieve installaties
  • Functie: Malware scanning, firewall, brute force protection
  • Kosten: Gratis (Premium €99/jaar voor real-time updates)
  • Setup tijd: 3 minuten

Setup Wordfence:

  1. Ga naar Plugins > Add New
  2. Zoek "Wordfence Security"
  3. Install & Activate
  4. Ga naar Wordfence > Scan en run je eerste security scan
  5. Enable two-factor authentication voor admin accounts

SEO Plugins

2. Yoast SEO

  • Downloads: 5+ miljoen
  • Impact: Sites met Yoast SEO scoren gemiddeld 23% beter in Google
  • Kosten: Gratis (Premium €89/jaar voor advanced features)

Yoast Setup Essentials:

  1. Install & Activate Yoast SEO
  2. Run de Configuration Wizard (SEO > General)
  3. Set je site type (Company/Person)
  4. Add je social media accounts
  5. Generate XML sitemap (automatisch enabled)

Performance Plugins

3. WP Rocket (Premium) of W3 Total Cache (Gratis)

  • WP Rocket: €49/jaar, 2.3x snellere laadtijden gemiddeld
  • W3 Total Cache: Gratis, complexere setup

Backup Plugins

4. UpdraftPlus

  • Functie: Automatische backups naar cloud storage
  • Kosten: Gratis voor basis features
  • Setup: Connect met Google Drive of Dropbox voor automatic offsite backups

Essential Plugins Installatie Workflow

  1. Security eerst: Wordfence → Two-factor auth setup
  2. SEO basis: Yoast → Configuration wizard
  3. Backups: UpdraftPlus → Connect cloud storage
  4. Performance: WP Rocket/W3TC → Enable caching
  5. Test alles: Check of je site nog steeds laadt

Plugin Management Best Practices:

  • Maximum 20 plugins - meer dan dat hurt performance
  • Test nieuwe plugins altijd eerst op een staging site
  • Deactiveer en delete plugins die je niet gebruikt
  • Update plugins binnen 48 uur na release (security)

Theme Installatie: Stap-voor-Stap

Methode 1: Via WordPress Repository

  1. Ga naar Appearance > Themes
  2. Klik "Add New"
  3. Zoek naar "Astra" of je chosen theme
  4. Click "Install" daarna "Activate"
  5. Ga naar Appearance > Customize voor basic settings

Methode 2: Upload Premium Theme

  1. Download je .zip theme file
  2. Ga naar Appearance > Themes > Add New
  3. Click "Upload Theme"
  4. Select je .zip file en upload
  5. Activate na successful installatie

Theme Customization Essentials

Na theme activatie:

  1. Site Identity:
    • Upload je logo (PNG format, 200x60px optimal)
    • Set site title en tagline
    • Choose site icon/favicon
  2. Colors & Fonts:
    • Kies 2-3 brand colors maximum
    • Selecteer web-safe fonts (Google Fonts integration)
    • Ensure contrast ratio > 4.5:1 (accessibility)
  3. Layout:
    • Set container width (1200px standard)
    • Choose sidebar layout
    • Configure header/footer

Stap 6: Content Creatie en Menu's (25 minuten)

Een lege website converteert 0% bezoekers. Je hebt minimaal deze pages nodig voordat je live gaat:

Essential Pages Checklist

1. Homepage

  • Doel: Explain wat je doet in 5 seconden
  • Elementen: Hero section, benefits, social proof, CTA
  • Length: 300-800 woorden

2. About Page

  • Conversie impact: 67% van bezoekers checkt deze page
  • Include: Your story, credentials, team photo
  • CTA: Contact form of calendar link

3. Services/Products Page

  • Focus: Benefits over features
  • Structure: Problem → Solution → Results
  • Include: Pricing (if appropriate)

4. Contact Page

  • Conversie rate: 2.5x hoger met contact form vs. email only
  • Include: Contact form, phone, address, business hours
  • Map integration (Google Maps embed)

5. Privacy Policy

  • GDPR requirement voor EU businesses
  • Generate via: WordPress Tools > Privacy Policy
  • Review en customize voor je specifieke situatie

Content Creation Workflow

Homepage Creation:

  1. Ga naar Pages > Add New
  2. Title: "Home" (je kunt dit later wijzigen in Settings)
  3. Use Gutenberg blocks of je theme's page builder
  4. Hero Section Template: 
       [Headline: What you do + who you serve]
   [Subheadline: Main benefit or outcome]
   [CTA Button: "Get Started" / "Learn More"]
   [Hero image or video]
  5. Add 2-3 benefit sections
  6. Include testimonials of social proof
  7. Eindigen met strong CTA

Menu Creation en Navigation

  1. Ga naar Appearance > Menus
  2. Create new menu: "Main Menu"
  3. Add pages: Home, About, Services, Contact
  4. Drag to reorder (most important first)
  5. Assign to location: "Primary Menu"
  6. Save Menu

Menu Structure Best Practices:

  • Maximum 7 top-level items (cognitive load)
  • Most important pages in positions 1-3
