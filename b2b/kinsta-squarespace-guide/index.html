Ik heb in de afgelopen acht jaar meer dan 40 websites gebouwd voor klanten, van simpele portfolio's tot volwaardige webshops. Squarespace was daarbij regelmatig de tool van keuze — en soms de tool die ik na drie maanden weer moest vervangen. In deze gids neem ik je mee door alles wat je moet weten om vandaag nog een professionele Squarespace-website te lancieren, inclusief de fouten die 90% van de beginners maakt en het punt waarop Squarespace simpelweg tegen zijn grenzen aanloopt.

Wat je in deze gids leert:

  • Hoe je in minder dan 2 uur een volledige website live zet, stap voor stap
  • Concrete pricing per plan (2025-tarieven) en wat je écht betaalt na jaar 1
  • Geavanceerde technieken zoals custom CSS-injectie en Developer Mode

Wat is Squarespace precies?

Squarespace is een all-in-one website builder: hosting, design, domeinregistratie en e-commerce zitten allemaal in één abonnement. Je betaalt niet apart voor hosting of een SSL-certificaat, wat het aantrekkelijk maakt voor starters. Het platform draait op een gesloten systeem — je hebt geen toegang tot de servercode, database of bestandsstructuur zoals bij WordPress.

Stap 2: Template kiezen (en waarom dit belangrijker is dan je denkt)

Squarespace heeft ruim 120 templates, verdeeld in categorieën als "Stores", "Portfolio" en "Professional Services". Klinkt veel, maar in de praktijk gebruiken 80% van de gebruikers dezelfde 15 templates — waardoor jouw site sprekend lijkt op duizenden andere sites.

  • Bruno: populair voor creatieve bureaus, maar zwaar (laadtijd gemiddeld 3,2 sec)
  • Mercer: lichte template, ideaal voor e-commerce, laadtijd gemiddeld 1,8 sec
  • Fulton: minimalistisch, veel gebruikt door consultants en coaches

Test laadtijden altijd via Google PageSpeed Insights voordat je een template definitief kiest. Een template die er mooi uitziet maar 4+ seconden laadt, kost je gemiddeld 7% conversie per extra secondie (bron: Google/SOASTA Research).

Stap 3: Domein koppelen of registreren

Je kunt een domein direct via Squarespace registreren (vanaf €20/jaar voor .com) of een bestaand domein koppelen via DNS-instellingen. Bij een bestaand domein:

  1. Ga naar Instellingen → Domeinen → Domein koppelen
  2. Kopieer de opgegeven A-records en CNAME's
  3. Plak deze in het DNS-paneel van je huidige registrar
  4. Wacht 24-48 uur op volledige propagatie

Stap 4: Paginastructuur opbouwen

Bouw eerst je sitemap op papier voordat je in de editor duikt. Een standaard MKB-website heeft:

  • Homepage
  • Over ons
  • Diensten/producten (met subpagina's per aanbod)
  • Blog (voor SEO-content)
  • Contact met formulier + Google Maps embed

Gebruik de drag-and-drop editor om secties te slepen. Werk met de "Fluid Engine" (sinds 2022 standaard) voor volledige controle over de layout op zowel desktop als mobiel — dit was voorheen een van de grootste tekortkomingen van Squarespace.

Stap 5: E-commerce instellen (indien van toepassing)

Bij Commerce Basic of Advanced:

  1. Voeg producten toe via Winkel → Producten toevoegen
  2. Stel betaalmethodes in: Stripe, PayPal, en sinds 2023 ook Klarna en Afterpay
  3. Configureer verzendzones en -tarieven onder Instellingen → Verzending
  4. Stel automatische e-mails in voor orderbevestiging en abandoned cart (alleen op Advanced)

Let op: Squarespace rekent bij Business-plan nog steeds 3% transactiekosten bovenop de betaalprovider-kosten (Stripe rekent zelf 1,4%-2,9%). Bij 10.000 euro omzet per maand betaal je dus €300 extra aan Squarespace alleen al aan platformkosten.

Stap 6: SEO-instellingen configureren

  • Stel per pagina een unieke SEO-titel en meta description in (max. 155 tekens)
  • Gebruik beschrijvende alt-tags op elke afbeelding — Squarespace vult deze niet automatisch aan
  • Koppel Google Search Console via Instellingen → SEO → Verificatie
  • Genereer een XML-sitemap (automatisch aanwezig op yourdomain.com/sitemap.xml)

Stap 7: Publiceren en analytics koppelen

Koppel Google Analytics 4 en Meta Pixel via Instellingen → Geavanceerd → Externe API's. Squarespace heeft ook eigen ingebouwde analytics, maar deze missen cruciale data zoals scroll-diepte en heatmaps — voor dat laatste heb je externe tools als Hotjar nodig.

Tips en best practices

  • Comprimeer afbeeldingen vóór upload naar max. 500KB via TinyPNG — Squarespace optimaliseert dit niet automatisch genoeg
  • Gebruik maximaal 3 lettertypes voor consistentie
  • Bouw mobile-first: 68% van het verkeer komt via mobiel (Statista, 2024)
  • Test formulieren wekelijks — een veelvoorkomend probleem is dat contactformulieren in spam belanden zonder dat je het weet
  • Maak gebruik van de ingebouwde AI-tools (Squarespace AI, gelanceerd in 2024) voor eerste concepten van productbeschrijvingen, maar herschrijf altijd voor merkstem

Veelgemaakte fouten

  1. Geen backup-strategie: Squarespace biedt geen ingebouwde versiehistorie van je volledige site zoals WordPress-plugins dat wel doen
  2. Te veel custom code toevoegen via Code Injection, wat laadtijden en toekomstige updates kan breken
  3. Verkeerde plankeuze: starten met Personal en later duur moeten migreren
  4. SEO-basis overslaan: geen alt-tags, geen meta descriptions, geen interne links
  5. Te veel afhankelijkheid van templates zonder eigen merkidentiteit toe te voegen
  6. Geen testfase op mobiel vóór livegang
  7. Vergeten domeinverificatie voor e-mail, waardoor transactionele e-mails in spam belanden

Geavanceerde technieken

Custom CSS-injectie

Via Design → Custom CSS kun je stijlen overschrijven die de visuele editor niet toestaat. Voorbeeld om de standaard knoppen aan te passen:

.sqs-block-button-element {
  border-radius: 8px !important;
  font-weight: 600 !important;
}

Developer Mode

Voor wie echt controle wil, biedt Squarespace "Developer Mode" via Git-integratie (alleen beschikbaar op Business-plan en hoger). Hiermee kun je templatebestanden lokaal bewerken met JSON-T en LESS. Nadeel: zodra je Developer Mode activeert, verlies je toegang tot de visuele Style Editor — een bewuste trade-off die Squarespace zelf ook waarschuwt.

Integraties via Zapier en API

Squarespace heeft geen open plugin-ecosysteem zoals WordPress. Voor koppelingen met CRM's (HubSpot, Salesforce) of e-mailmarketing (Mailchimp, Klaviyo) ben je afhankelijk van Zapier-workflows of de beperkte native integraties.

Wanneer Squarespace niet meer genoeg is

Dit is het punt waar de meeste gidsen stoppen — maar waar het voor jou als ondernemer juist interessant wordt. Squarespace is fantastisch tot een bepaald schaalniveau, maar loopt tegen structurele grenzen aan:

Geen toegang tot serverconfiguratieGeen custom caching, geen CDN-regels op maat

Geen eigenaarschap over hostingBij account-issues kan je site offline gaan zonder eigen controle

Veel van mijn klanten die groeien richting complexere B2B-websites met offerteaanvragen, klantportals of gepersonaliseerde content, lopen binnen 12-18 maanden tegen deze muur aan. Het alternatief dat ik dan altijd adviseer: WordPress, gehost op een managed platform zoals Kinsta.
