The 50% sale is 38% on the product you want

Everything here is a meter — per GB, per IP, per 1,000 responses — and the rates we captured were sale rates. Residential proxies ran from $0.65 a GB against a $1.05 list, mobile $2.20 a GB, and static ISP and datacenter proxies from $0.75 an IP against a $1.50 list. On the API side, SERP API is $0.70 per 1,000 responses, Web Scraper API $0.50, Web Unlocker $1.00 and Scraping Browser $2.50 a GB.

The promotion was billed as roughly 50% off, and on the IP products it is exactly that — $0.75 from $1.50. On residential, which is the product most people are actually here for, $0.65 from $1.05 is 38%. Worth knowing which discount you are being shown. More importantly, list prices are published for only two of the eight lines above: for mobile, the SERP API, the Web Scraper API, the Web Unlocker and the Scraping Browser, we have no idea what the post-sale rate will be.

Budget on list where you can see it and ask for list where you cannot, because a promotional rate you build a pipeline around is a price rise waiting to happen. Two unit comparisons worth carrying into the decision. The Web Unlocker at $1.00 per 1,000 is twice the Web Scraper API at $0.50, and that difference is the anti-bot premium. It is only worth paying on the targets that need it, so route by site rather than sending everything through the expensive path.

And the Scraping Browser at $2.50 a GB is 3.8 times the residential proxy rate, which understates the gap: a full browser session transfers far more per page than a raw fetch, so you pay a higher rate on more gigabytes. Use it where JavaScript rendering is genuinely required and nowhere else. Free trials run on the APIs, and the sensible way to use them is to measure your own bandwidth per page on your own targets.

That figure, multiplied by list price, is your real monthly cost. It is the only number that makes any of these rates comparable to a competitor's. One caveat we would give any residential-proxy vendor, not just this one: those hundred-million-plus residential IPs come from consumer devices. Check how they were sourced and check your target sites' terms before you build anything on top of it.

How to actually use Thordata

Measure your bandwidth per page before you compare any rate. Use the free API trials on your own targets and record how many megabytes a typical page costs you — that number multiplied by the per-GB rate is your actual bill, and without it no proxy vendor's pricing can be compared to another's. Budget on list prices, not the ones you see. The rates we captured were promotional: residential at $0.65 a GB against a $1.05 list, static IPs at $0.75 against $1.50.

And for five of the eight product lines no list price is published at all, so ask what the standard rate is for anything you plan to depend on. Route by target rather than by habit. The Web Unlocker costs twice the plain Web Scraper API, and the Scraping Browser costs nearly four times the residential proxy rate per gigabyte while also using more gigabytes per page. Send only the sites that genuinely need anti-bot handling or JavaScript rendering down the expensive paths.

Before any of that, check the sourcing. Residential IPs come from consumer devices, so ask how the network was built and read your target sites' terms — that question belongs at the start of this project, not after it is in production.
