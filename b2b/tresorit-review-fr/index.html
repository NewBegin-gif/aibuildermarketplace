Ce qu'est réellement Tresorit

Tresorit est un stockage cloud chiffré de bout en bout et un partage sécurisé de fichiers. Le mot clé est connaissance nulle : vos fichiers sont chiffrés sur votre propre appareil avant d'atteindre les serveurs de Tresorit, donc l'entreprise elle-même ne peut pas les lire. C'est la différence architecturale avec les clouds grand public — et une fois que vous avez manipulé du matériel vraiment confidentiel, c'est difficile de ne plus le voir.

  • Chiffrement à connaissance nulle. Les fichiers sont chiffrés côté client ; seuls vous (et les personnes avec qui vous partagez explicitement) pouvez les déchiffrer. Tresorit ne peut pas, et personne qui pirate Tresorit non plus.
  • Partage sécurisé avec contrôle. Partagez des liens chiffrés avec permissions, mots de passe, dates d'expiration et possibilité de révoquer l'accès — pour qu'un contrat que vous envoyez à une contrepartie ne vive pas éternellement dans la boîte mail de quelqu'un.
  • Fonctionne partout. Applications de bureau pour Windows, Mac et Linux, applications mobiles pour iOS et Android, plus accès web sécurisé — les fichiers se synchronisent et vous suivent entre appareils.
  • Conçu pour la conformité. Protection des données UE/Suisse avec une posture de confidentialité visant le travail réglementé (juridique, finance, santé) — le genre de paperasse dans lequel je vivais.
