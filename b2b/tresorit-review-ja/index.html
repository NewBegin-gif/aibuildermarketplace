何年もの間、私はそれらを誰もが使う主流のクラウドに保管していました。便利です。しかし、それは私のデータの鍵を保持し、スキャンする権利を留保するサービスでもあります。それが十分に気になった日、私は逆の方法で構築されたストレージを探し始めました — 私が鍵を保持し、プロバイダーが文字通り私のファイルを読めない場所です。その探索はTresoritで終わりました。これが私の正直なレビューです。

Tresorit が実際に何であるか

Tresorit はエンドツーエンド暗号化クラウドストレージと安全なファイル共有です。キーワードはゼロ知識:あなたのファイルは Tresorit のサーバーに到達する前にあなた自身のデバイス上で暗号化されるため、会社自体がそれらを読むことができません。これが大手クラウドとのアーキテクチャの違いです — そして本当に機密性の高い資料を扱ったことがあれば、これを見過ごすことは難しいです。

  • ゼロ知識暗号化。ファイルはクライアント側で暗号化されます。あなた(および明示的に共有する人)だけがそれらを復号化できます。Tresorit はできませんし、Tresorit を侵害した人もできません。
  • コントロール可能な安全な共有。権限、パスワード、有効期限、アクセス取り消し機能を持つ暗号化リンクを共有 — 取引相手に送った契約が誰かの受信箱に永遠に残ることはありません。
  • どこでも動作。Windows、Mac、Linux 用のデスクトップアプリ、iOS と Android 用のモバイルアプリ、さらに安全な Web アクセス — ファイルは同期され、デバイス間で追従します。
  • コンプライアンスのために構築。規制された業務(法律、金融、医療)を対象としたプライバシー姿勢を持つ EU/スイスのデータ保護 — 私がかつて生きていた種類の書類です。

Tresorit では、暗号化はアップロード前にあなたのラップトップ上で行われ、鍵はあなたのコントロールを離れることはありません。明日誰かが Tresorit を侵害したとしても、彼らが得るのは暗号化されたノイズです。金融では誰が何を見ることができるかに執着していました。Tresorit はその規律の消費者版です。私が気にするフォルダ — クライアント作業、契約、NDA 下のもの — にとって、これはあったら良いものではなく、要件です。
