If you built a site or an app with an AI tool, the next question is where it runs — and the hosts on this page are not interchangeable. A landing page, an app with a backend and a database, a WordPress site and a model that needs a GPU each want a different kind of home, and each host bills for something different: resources by the second, a managed server by the hour, a site on a prepaid term, or GPU time. The headline prices are real, but they are the smallest box. What decides the bill is what you add — backups, a database, bandwidth, the renewal after a prepaid term, or the hours a GPU sits idle. Every figure below was read on the vendor's own pricing page, on the date shown.

How to choose

Decide what has to run before you compare prices. A static site needs no server at all: DigitalOcean's App Platform hosts three static-site apps on its free tier. An app with a backend needs a server or a managed runtime and usually a database, and that is where cloud bills grow — on DigitalOcean a 2 GiB Droplet ($12), daily backups ($3.60) and the smallest managed database ($15) come to $30.60 a month before bandwidth. A WordPress site wants a host that runs the stack for you. A model wants a GPU, and the meter there is time, so an idle GPU still bills. Then price the second year: prepaid shared hosting renews higher (Hostinger's $2.99 renews at $10.99), while cloud and GPU billing has no term but no ceiling either — set a billing alert on day one.

Frequently asked questions

Is a cloud server cheaper than managed hosting?

For the same machine, yes, but you do the work. Our Cloudways dossier compares the same 8 GB machine: $48 a month as a DigitalOcean Droplet against $99 a month on Cloudways, which adds the managed stack and platform support. Whether the difference is worth it comes down to whether you want to look after a server.

Is there a free way to host what I built?

For a static site, yes: DigitalOcean's App Platform hosts three static-site apps on its free tier, with 1 GiB of transfer each (read 3 October 2026). Anything that runs server code — an API, a database, a model — is paid on DigitalOcean, from $4 a month for the smallest Droplet.

What does a GPU cost if I leave it running?

Time is the meter, so an idle GPU still bills. On the rates we read, an H100 SXM pod on Runpod's Secure Cloud is $3.49 an hour (24 September 2026) and an NVIDIA HGX H100 on DigitalOcean is $4.41 per GPU-hour on demand (3 October 2026). Left running for a 720-hour month, that is $2,512.80 and $3,175.20.
