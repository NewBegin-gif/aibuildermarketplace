FREE MCP SERVER · RUNS LOCALLY

Give your AI honest pricing data

AI assistants guess at SaaS prices — or repeat vendor marketing. The Honest Atlas MCP gives Claude, Cursor or any MCP client direct access to 300 hand-researched tool dossiers: real pricing notes, the honest knock, who each tool is genuinely for, and who should skip it. No invented numbers, ever.

77 seconds: what it does, what you can ask, and the 30-second install.

Install (30 seconds)

Claude Code
curl -fsSL https://aibuildermarketplace.com/mcp/atlas_mcp.py -o ~/.atlas_mcp.py
claude mcp add honest-atlas -- python3 ~/.atlas_mcp.py
Claude Desktop / Cursor — download atlas_mcp.py, then add to your MCP config:
{
  "mcpServers": {
    "honest-atlas": {
      "command": "python3",
      "args": ["/Users/you/.atlas_mcp.py"]
    }
  }
}

Requirements: just Python 3.8+. Zero dependencies, ~300 lines you can read yourself. It fetches the public dossier feed once a day and runs entirely on your machine — no accounts, no tracking.

Then ask your AI things like

  • “What’s the honest take on Miro before I roll it out to 40 people?”
  • “Compare Kit and Brevo for a 10k-subscriber newsletter — real costs.”
  • “Find me email marketing tools with a genuinely free tier.”
  • “Which project tools won’t charge me per seat?”

Tools it exposes

  • search_tools — find tools by need, with honest one-liners + pricing
  • get_dossier — the full honest dossier for one tool
  • compare_tools — 2-4 tools side by side
  • list_categories — orient a search

Why this exists

We hand-research the pricing of every tool we partner with and publish every cost-trap with its evidence (the Atlas, open dataset, the Awards). AI assistants are where buying decisions increasingly happen — they deserve the honest version too.
