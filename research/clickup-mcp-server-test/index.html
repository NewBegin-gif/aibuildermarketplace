ClickUp’s MCP server, tested with Claude Code: tasks, comments and subtasks worked, and so did delete

On the morning of 12 November 2026 we connected Claude Code, Anthropic’s coding agent, to ClickUp’s hosted MCP server and had it run a small project from the command line: make a list, create a task with a due date and priority, comment on it, add a subtask, find it again, move it along and delete it. Everything worked on a workspace with no paid ClickUp plan. One result did not match the line we had published from ClickUp’s docs: delete is available.

How we tested

  • Connection. We added the server URL https://mcp.clickup.com/mcp to Claude Code as a remote (HTTP) server and signed in once through ClickUp’s own OAuth page in the browser. No API key to copy.
  • Our own test workspace. The workspace from our earlier ClickUp test, with one space and no paid plan: ClickUp shows an Upgrade button in the sidebar.
  • Plain-language instructions. Claude Code (on Anthropic’s Sonnet model) got a numbered list of steps and had to pick the tools itself. We logged each tool call, its input and the answer.
  • Checked in ClickUp, not just in the answers. Afterwards we opened the task in ClickUp in the browser (screenshot below).

What it means if you use ClickUp

The server does what a project tool’s API should: an agent can turn a request like “make a task for the pricing review, due next Friday, high priority, with a subtask for the competitor check” into the right objects, and you see them in ClickUp seconds later. Every action is recorded under your own name; the comment in our screenshot shows as written by the account owner, with nothing marking it as written by an agent.

Two things to set up before you let an agent loose. First, delete is available and cascades to subtasks, so if you only want an assistant that adds and updates, tell your MCP client to ask before every call or block the delete tool. Second, the free limit is per rolling 24 hours: ClickUp’s MCP page lists 100 calls on Free Forever, 300 on Unlimited, 1,000 on Business, 2,500 on Business Plus and 5,000 on Enterprise, or the normal API limits if you buy the Everything AI add-on. Our whole test used 19; a busy day of agent work would not fit in 100.

Want to try it yourself? The MCP server works on ClickUp’s free plan, so you can connect it without paying: start a free ClickUp workspace (our affiliate link).

What this test does not show

  • Docs, whiteboards and goals. We tested tasks, lists, comments, subtasks, search and status, not ClickUp Docs or the other areas the server covers.

  • Teams and permissions. One owner account; we did not test what a guest or a member with fewer rights can do through the server.
