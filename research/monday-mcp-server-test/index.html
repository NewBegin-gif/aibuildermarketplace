Hands-on test · run on 2026-11-12

monday.com’s MCP server, tested with Claude Code: everything worked on the Free plan, nothing worked after an expired trial

On 12 November 2026 we connected Claude Code, Anthropic’s coding agent, to monday.com’s hosted MCP server and asked it to build a small board: columns, items, a comment, a status change and a count per status. The first run happened to hit an account whose Pro trial had ended, and the server refused almost everything with a bare “403”. After we moved the account to monday’s Free plan, the same steps all worked.

On monday’s Free plan, Claude Code built a board through the MCP server in 13 calls: two columns, two items, a dated status, a comment and a count per status. How we tested

  • Connection. We added https://mcp.monday.com/mcp to Claude Code as a remote (HTTP) server, the endpoint monday publishes in its machine-readable card at monday.com/.well-known/mcp.json, and signed in once through monday’s OAuth page.
  • Our own test account, from our earlier monday test, with one member. Its Pro trial had ended; we only found that out from the first run (below).
  • Plain-language instructions. Claude Code (on Anthropic’s Sonnet model) got numbered steps and picked the tools itself. We logged each call, its input and the answer, and checked the board in monday afterwards.

What it means if you use monday.com

monday says in its own MCP FAQ that MCP is available on all plans at no extra cost, and on the Free plan that held up: everything we asked for worked, in 13 calls. The board in monday also showed “AI credits used up” while the MCP calls went through, so in our test the MCP work did not draw on monday’s own AI credits.

The weak spot is the error message. When an account is in a state the app blocks, such as an ended trial, the server answers with a generic 403, and an agent cannot tell a missing permission from a missing plan. Two more things to know before you connect an agent: there is no delete tool, but all_monday_api can run any GraphQL request your account is allowed to make, deletes included; and labels follow your account language, so an agent working in English may get Dutch, German or French status names back.

Want to try it yourself? Everything above worked on monday’s Free plan: start with monday.com (our affiliate link). If you are offered a free Pro month that needs a card, the Free plan is the small link at the bottom of that screen.

Screens from the test

One more thing we noticed on the way to the Free plan: monday’s downgrade path first offers another 30 days of Pro for €0, with card details required and billing from day 31 unless you cancel. The Free plan is a small link at the bottom of that screen.

What this test does not show

  • Paid-plan features. Automations, dashboards, private boards and guests through MCP on Standard or Pro: not tested.
  • Monday’s agent and Vibe tools. The server also offers tools for monday’s own agents and Vibe apps; we did not use them.
  • Large boards. Two items; we did not test paging through thousands.
  • Other clients. Only Claude Code.
