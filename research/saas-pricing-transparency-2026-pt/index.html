O preço anunciado só é a história completa em 33% do software de negócios

Investigámos à mão os preços de 248 ferramentas de negócio e documentámos, com evidência, cada estrutura que afasta o custo real do preço anunciado. O resultado: 167 de 248 ferramentas (67%) carregam pelo menos uma ressalva de custo documentada — medidores de uso, preço por utilizador, extras pagos, fidelizações anuais, preços ocultos ou aumentos na renovação. Cada número desta página é calculado a partir do nosso conjunto de dados aberto.

Metodologia — e os seus limites honestos

Como nascem os números. Cada ferramenta do corpus tem um dossiê investigado à mão. Uma marcação só conta se o dossiê contiver uma frase de evidência explícita — as mesmas regras de classificação que alimentam o Honest Software Atlas. Esta página é reconstruída a partir do corpus; os números não podem divergir da fonte.

O que este corpus não é. Não é uma amostra aleatória do mercado: cobre as 248 ferramentas que investigamos e analisamos, com viés para ferramentas com programa de afiliados. As percentagens descrevem este corpus, não a indústria inteira. Os dados brutos são abertos (CC BY 4.0) — qualquer pessoa pode refazer a análise.
