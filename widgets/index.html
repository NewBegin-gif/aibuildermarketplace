Embed any tool, anywhere

Drop a live, always-up-to-date tool card into any blog post or page with one line of HTML. Update the data here once — every embed everywhere updates with it.

How it works

  1. Add the script once per page (it's tiny and async).
  2. Place a <div class="aibm-widget" data-tool="..."> wherever you want a card.
  3. It renders a branded affiliate card pulled live from our central database — logo, description and a tracked call-to-action.
  4. Change a link or price in the hub and every widget across all your blogs updates automatically. No manual edits, ever.

Copy & paste

<div class="aibm-widget" data-tool="Clay"></div>
<script async src="https://aibuildermarketplace.com/aibm-widget.js"></script>

Use the exact tool name as the data-tool value (case-insensitive). Add as many cards as you like — the script loads the data only once.
